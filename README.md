## v3.2.0 更新

本次属于功能调整。

- 删除“我克制谁”功能
- 页面只保留 **主要被克制关系**
- `data.xlsx` 的 `counters` Sheet 已删除所有 `strong` 行，只保留 `weak`
- 路霸的坦克被克制列表中移除 **D.Va**
- 末日铁拳的输出位被克制列表中加入 **回声**

### 回声 → 末日铁拳

原因：

回声可以利用飞行和垂直机动保持在末日铁拳不容易直接贴身的位置，迫使铁拳先消耗火箭重拳或猛击来接近；一旦铁拳把机动技能用于进场，撤退资源就会减少。

当末日铁拳生命值降到半血以下时，回声的聚焦光线伤害会显著提高，非常适合在他交完防御或位移资源后快速完成收割。

## 数据结构

`counters` 现在只使用：

```text
relation = weak
```

表示：

```text
谁克制当前英雄
```

不再维护 `strong` 数据。

## 自动生成

以后修改 `data.xlsx` 后上传 GitHub：

```text
data.xlsx
→ GitHub Actions
→ python build.py
→ 自动更新 index.html
```

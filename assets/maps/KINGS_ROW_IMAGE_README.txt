King's Row 实际俯视图放置说明

1. 打开 StatBanana Overhead Maps：
   https://overwatch.statbanana.com/images

2. 找到 King's Row。

3. 下载 Low resolution PNG (1000x1000)。

4. 将下载后的文件重命名为：
   kings-row.png

5. 放到当前目录：
   assets/maps/kings-row.png

项目会自动读取该本地文件，并在上方叠加 SVG 路线。

来源要求：
- 非商业用途
- 不要原样重新分发
- 保留原图 Logo，或者在网页附近注明：
  Overhead map courtesy of https://statbanana.com/

当前网页已经保留 StatBanana / Coggle 的署名和来源链接。
